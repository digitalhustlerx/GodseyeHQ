**Root cause:** The live nginx config's `location = /` block had been changed (config mtime **09:55 today**, ~13 min before this run; the `.bak` at 09:42 still held the correct version) from:

to:
```nginx

    add_header Cache-Control "no-cache, no-store, must-revalidate, max-age=0";
    add_header Pragma "no-cache";
    try_files /index.html =404;                 # WRONG — serves SPA shell at root
```
