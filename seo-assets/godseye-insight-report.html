How a power user actually runs an AI agent.

Source: real telemetry · 30 days of autonomous + interactive operation (Jul 04 – Aug 03, 2026). Every number is actual usage — not a benchmark, not a projection.

The headline — read this first

A solo founder ran a full multi-project software business on an AI agent for 30 days. The operation processed 2.26 billion tokens, executed 48,185 real actions, and ran 133 daily sessions — at a measured compute cost of roughly $49 for the month. For every action the founder took, the agent took 8 more on its own.

4 · The economics

Input tokens: 115.7M Output tokens: 16.2M Compute cost (30d): ~$49 Cost per day: ~$1.64 Cost per session: ~$0.012
The single most persuasive number here: an entire solo-business operation, 30 days, for the cost of a cup of coffee per day.

5 · The scale multiplier

Basic user: ~400K tokens/day, ~$3/month Power user: ~75M tokens/day, ~$564/month (fully-loaded) Ratio: ~188× Autonomy: 8.1 agent-actions per 1 human action

Even at 188× a basic user, the cost stays in the tens-to-hundreds range for a month. The agent grows with you without exploding your bill.

6 · Capability proof

  • 4,001 sessions, 48,185 tool actions, 87,147 messages of real production load
  • Multi-project orchestration carried simultaneously (SaaS build, checkout, Telegram bot, WP plugin + more)
  • Self-healing: the agent autonomously diagnosed and fixed production issues (a broken bot token, a leak, a polling bug)

7 · The honest caveats

  • Throughput ≠ completion — the data shows enormous doing, but shipping took discipline; the agent can't force it
  • Autonomy compounds — more agents burn more background tokens (44% autonomous)
  • Budget toward the fully-loaded number, not the clean one; schedule background agents to need
A power user isn't defined by asking more questions — but by delegating more execution. One agent carried a full multi-project business for 30 days and ~48,000 real actions for about $49 of measured compute. The agent is a department, not a tool.
