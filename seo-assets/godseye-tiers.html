Three ways to run GodsEye.

Same agent — you pick how much it controls. Read each plan in plain language below.

1 · Starter — the safe assistant ($9–12/mo)

Your WordPress stays on your hosting.

  • ✓ List, draft, and edit posts & pages (drafts only — never publishes on its own)
  • ✓ Moderate comments (approve / unapprove / trash)
  • ✓ Manage products across your store (WooCommerce)
  • ✓ SEO + site-health checks, plugin/theme status, flush cache
  • ✓ Every request is signed, timestamped, and expires in 5 minutes

2 · Pro — the full operator

Deeper control. It installs, fixes, and maintains.

Everything in Starter, plus the power to actually run your site — with your approval for anything high-impact.

  • ✓ Draft and publish content (with your OK)
  • ✓ Install & activate plugins and themes
  • ✓ Edit pages with page-builders (Elementor + others)
  • ✓ Backups, restore, and security hardening
  • ✓ Run scheduled autonomous tasks
  • ✓ Direct server config + database management via WP-CLI

3 · God Mode — we run it all for you

A full-time AI operations team as a service.

You hand over the keys — we host, manage, update, harden, and watch over your whole stack. You get a site that's looked after around the clock.

  • ✓ GodsEye hosts + provisions the server for you
  • ✓ We install WordPress, the bridge, plugins, and theme
  • ✓ We keep everything updated, hardened, and healthy
  • ✓ You get a full-time AI ops team on the job
Honest note on safety: Starter is deliberately safe (draft-only, signed requests). Pro adds real power, so high-impact actions need your approval.
